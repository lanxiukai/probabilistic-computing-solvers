# 对称旅行商问题

[English](README.md) | 简体中文

本次公开主体为**候选弧GPU p-bit热浴更新流程**，由经典初始化、匹配、子环修复及局部搜索提供支撑。见[方法与复现](candidate-network.zh-CN.md)及[RTX 5090实测报告](candidate-report.zh-CN.md)。七个实例覆盖200–2103城，单模型最多33,662个二值节点，8个副本另计。没有一次调用改善LKH前缀，200城最优已存在于该前缀。这些是混合流程结果，不代表p-bit独立收益或完整TSP Ising基态。

独立LKH与GA-EAX作为经典参照，[u1817 CPU证书](../../data/tsp/candidate-network/u1817-optimum.json)归属于GA-EAX。新的云端测量仅包含p-bit流程、三种归因对照及另行原点回放。

源码位于`src/combinatorial_solvers/tsp/`，同时保留排列、one-hot及AB-cycle接口。[旧150城报告](experiment-report.zh-CN.md)保留CPU p-bit选择器／GPU局部搜索方法与原分母，其结果与本候选网络研究分开。合成`tsp`示例检查旧证书链，无需TSPLIB或原生求解器；实测候选流程使用方法指南中的显式命令。

使用[通用复现步骤](../reproduction.zh-CN.md)与[外部参照清单](../external-baselines.zh-CN.md)，按作者条款取得字节匹配的外部输入及原生源码。不再分发原生二进制、基准坐标或论文文件。
