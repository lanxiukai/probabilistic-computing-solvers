# 两两覆盖数组

[English](README.md)

GPU模拟的p-bit块热浴在固定行数下搜索覆盖数组。模型要求任意两列覆盖全部符号对，使用等大小字母表，不含禁用组合。目标函数直接计算原问题的缺失交互数；零缺失才证明给定行数可行。

冻结确认面板评估五种维度、三个新种子，每个原生调用包含128个副本；共15个热浴调用、30个匹配经典对照调用，以及5个独立ACTS/IPOG构造调用。三个固定工作量回放不增加独立试验数。另行保留的开发面板包含10个自然调用和1个回放，不属于新种子确认。最大评估模型每个副本含31,500个持久化one-hot二元条目。评估规模本身不证明找到可行数组，也不证明热更新有收益。

- [模型、更新规则与贡献归因](method.zh-CN.md)
- [冻结协议、结果与局限](report.zh-CN.md)
- [源码地图与复现](source-guide.zh-CN.md)

实现是在RTX 5090上模拟受约束的p-bit状态；不构成物理p-bit器件、硬件速度优势或当前最好已知行数的展示。

独立确认的15次热浴调用和15次plateau调用均构造成功，最大成功编码31,500位；30行节点plateau的副本命中率更高，因此未建立热浴独立优势。
