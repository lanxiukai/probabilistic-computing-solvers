# QAP：RTX 5090独立确认

[English](experiment-report.md) · [模型与参考资料](README.zh-CN.md)

条件p-bit流程在九次新种子Nugent调用中全部达到目录最优值；九次Taillard调用均未达到冻结的历史参考。`tai150b`最好代价为**499,088,558**，比参考498,896,643高**0.0384679%**。可行性用原始整数矩阵认证；相对可行参考的差距不是最优性差距。

流程从均匀随机排列出发，没有经典搜索前缀、参考解初始化或末端精修。原始目标计算与保持约束的提议属于经典支撑。匹配CUDA Metropolis／plateau及两种独立CPU禁忌算法作为参照。结果说明限定范围的优化能力，不是物理p-bit硬件测量或普遍经典优势。

## 冻结确认与基准

Q2在观察结果之前冻结种子`2026102411/2026102412/2026102413`。六个原始QAPLIB输入分别运行热浴、匹配Metropolis、plateau和单CPU worker属性禁忌，共**72次确认调用**。另有四次固定工作量实现调用及五次回放，共81个保留记录。声明调用全部完成，没有从分母剔除未命中。

原始输入及参考排列按固定身份从[QAPLIB镜像](https://coral.ise.lehigh.edu/data-sets/qaplib/qaplib-problem-instances-and-solutions/)下载，不随仓库再分发。目录保留参考排列的下标及取逆约定。`nug20`、`tai40a`、`tai80a`为留出输入；`nug12`、`nug30`、`tai150b`曾用于开发。自然规模端点为22,500个受约束one-hot条目，没有人为填充到32K，也不等于独立物理器件数。

原生调用均使用四位置块、四个warp、每块512次更新和精确分解能量计算。Nugent使用128副本、4,096步周期及归一化逆温度系数1–64；Taillard使用512副本、65,536步周期及系数1–256。每个系数除以`sqrt(n) * mean(A) * mean(B)`，均值包含零和对角项。搜索上限为nug12的5秒、nug20／nug30的15秒及Taillard的30秒；属性禁忌参照使用单CPU worker和相同名义时限。

每个chunk都观测；完整检查点目标间隔为两秒，粗状态快照按开发吞吐冻结，覆盖至少131,072次更新及约两秒开发搜索。质量只计原始截止前已完成并观测到的chunk／迭代；保留的越界工作不计质量。回放保留原始工作量与质量边界，不增加试验。控制组复用热浴选定的参数，没有同等预算的独立调参。

## 源码身份、核验及限制

全部原档已回收并独立审计：Q2保存状态2,020,690个，Q1c为1,186,944个，Q3为5,085个。公开核心保留完整调用名册、初态／当前／返回最好／合格见证、one-hot／参与／RNG状态及精简后的改善和边界观测，不冒称包含全部私有轨迹快照。详见[Q2面板](../../data/qap/rtx5090/panel.json)、[调用台账](../../data/qap/rtx5090/calls.json)和[复现说明](README.zh-CN.md#基准与复现)。

公开七模块包经命名空间替换和格式化后，与已执行的Q3共享源码版本一致；其中六个模块及原生runner分支也与Q2／Q1c一致。runner另外增加官方外部参照分发及额外源码输入绑定，这一差异在[来源记录](../../provenance/qap/release.json)中明确保留。计时属于各原始执行面板。九次公开源码回放分别匹配原始非计时数组：原生20个、自研禁忌13个、官方Ro-TS 17个。组装公开树788项软件测试全部通过、无跳过，随后完成核心证书与内容检查。

本研究没有闭合Taillard参考，没有建立当前最好纪录、平衡采样证明或硬件能耗比较，也没有复现所引用的p-dit、学习MCMC和量子退火系统。每设置三个种子、每输入一次实现计时配对限制了泛化范围。强对照、未命中及资源差异都是公开结果的一部分。

以下来源核对于 2026-10-23。其性能主张尚未在本专题复现，不跨硬件、实例面板和计时定义直接排名。

- [Lehigh QAPLIB](https://coral.ise.lehigh.edu/data-sets/qaplib/qaplib-problem-instances-and-solutions/)：输入及参考见证。此次核对时 Montreal 主站不可用，发布采用固定哈希的镜像原件。
- É. Taillard，[Robust taboo search for the quadratic assignment problem](https://mistic.iict-heig-vd.ch/taillard/articles.dir/Taillard1991.pdf)，*Parallel Computing* 17，443–455（1991），[DOI](https://doi.org/10.1016/S0167-8191(05)80147-4)：经典方法背景与独立对照实现的设计依据。
- É. Taillard，[官方标准 C 版 Ro-TS 源码](https://mistic.iict-heig-vd.ch/taillard/codes.dir/tabou_qap2.c)，标注 2006-03-14：单独下载的外部实现，采用非均匀期限；其非商业条件与自有适配的许可分开。
- G. Paul，[GPU 模拟退火求解 QAP](https://arxiv.org/abs/1208.2675v1)，2012 年预印本：早期 GPU QAP 退火，本专题不主张首次使用 GPU 求解 QAP。
- C. Novoa、A. Qasem，[GPU 加速的 QAP 并行求解](https://arxiv.org/abs/2307.11248v1)，2023 年预印本：GPU 2-opt 与禁忌搜索实现，尚未在当前设备复现其性能。

- Y. Pan 等，[Learning to Solve the Quadratic Assignment Problem with Warm-Started MCMC Finetuning](https://arxiv.org/abs/2604.20109v1)，2026 年预印本：PLMA 结合学习式排列模型与 MCMC 适应，未来同口径比较需计入训练和适应成本。
- M. Kuramata、R. Katsuki、K. Nakata，[量子退火与比特翻转启发式求解稀疏 QAP](https://arxiv.org/abs/2012.10135v3)，ICIEA 2021：量子退火与经典修复背景，不同约束编码及硬件不能仅凭规模比较性能。
- G. Yan 等，[Rethinking Parity Check Enhanced Symmetry-Preserving Ansatz](https://proceedings.neurips.cc/paper_files/paper/2024/hash/7798f18a1e91aff7ad1df4841d6a01a8-Abstract-Conference.html)，NeurIPS 2024：摘要级变分量子算法硬约束背景，含 QAP，尚未复现。
- [Python](https://www.python.org/)、[NumPy](https://numpy.org/)、[PyTorch](https://pytorch.org/)、[Triton](https://github.com/triton-lang/triton)、[CUDA](https://docs.nvidia.com/cuda/)、[GCC](https://gcc.gnu.org/)、[uv](https://docs.astral.sh/uv/)、[pytest](https://docs.pytest.org/) 和 [Ruff](https://docs.astral.sh/ruff/)：实现、环境和检查工具，具体版本以发布锁文件和实测环境记录为准。
