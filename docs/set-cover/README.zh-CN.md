# 加权集合覆盖

[English](README.md)

GPU 模拟的 p-bit 块热浴从经典贪心覆盖出发，在始终满足原始覆盖约束的条件下改进费用。验收的 RTX 5090 面板保留全部 117 次自然调用：九个公开实例、热浴及三种对照各三枚新种子，另有九次 LP/MILP 参照。四次工作回放不增加独立试验数。

27 次热浴调用全部改善贪心前缀，15 次达到冻结目标。相对匹配 Metropolis 和允许中性移动的下降对照，胜／平／负分别为 15/12/0 和 19/8/0；相对强经典 CPU AC-CFT 为 0/16/11。本次发布支持所测块求解流程中的增量收益，不支持超过专门集合覆盖求解器的结论。

最大的完整模型是 `rail516`：每副本 47,311 个原始二元决策，128 副本，零辅助 p-bit。热浴返回 184/185/185，独立证明的最优值为 182。完整运行器平均耗时 38.3254 s，CUDA 分配器的峰值 allocated 为 228.638 MiB、reserved 为 236.000 MiB。这些数据来自 GPU 模拟，不是物理 p-bit 器件演示。
