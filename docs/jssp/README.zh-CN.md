# 作业车间调度

[English](README.md)

本专题用 GPU 模拟的条件 p-bit 更新，在可行优先序上求解静态作业车间调度。经典确定性解码器提供时间表及原始整数 makespan；匹配邻域的 CUDA 对照和单 worker OR-Tools CP-SAT 用于检验热更新规则的收益、持平或劣势。

已验收的确认覆盖六个输入、三个新种子和四种方法，共 72 次调用及三次固定工作重放。热浴在其 18 次调用中的 12 次达到参考最优值，均无冷初态参考命中。留出输入 ft10 的副本命中分布优于匹配控制；两个 Taillard 输入仍高于参考值，且单 worker CP-SAT 在每个输入上的平均完整时间更短。

对于 $J$ 个作业和 $M$ 台机器，显式二元表示包含 $J^2M$ 个赋值项。因此，50 × 15 基准每副本包含 37,500 项；这是编码规模端点，不代表前沿调度难度或物理器件规模。初始化和确定性解码属于经典支撑，改进须与匹配对照分别比较。
